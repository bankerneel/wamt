Who Ate My Tokens?

your agents, caught snacking live

A local, read-only token observation layer for T3 Code, Claude Code and Codex. It shows live threads and subagents with the model behind each one, the 5-hour and weekly limits, a 30-day history and API-equivalent cost by project. One Rust binary, one page, and nothing leaves your machine.

Live view

Every active T3 Code thread with its subagents, model, current step, context fill and tokens so far. Click a row, or press Enter, for that thread's runs, tool counts and a 10-minute token timeline.

Claude Code and Codex sessions outside T3 appear as their own lanes. Press / to filter by title, project, branch or model. The tab title and favicon show the plate and anything waiting on you.

Limits

A 5-hour plate with a run-out forecast from the last 30 minutes, plus Codex's own limit line.

A weekly meter. When Claude Code's status line reports rate_limits, those numbers become the hero percentage and reset time, and the local estimate is shown alongside. A manual "Calibrate from /usage" fallback is kept only in this browser.

History and cost

Today against yesterday and the day before, then the week so far and a compact 30-day strip stacked by model family.

PRs with CI checks and review states, spoiled leftovers (requests that rebuilt over 50K tokens of expired cache) and API-equivalent dollars at list prices. "Who ate it, by project" rolls 30 days up by T3 project title, or by working-folder name outside T3. Copy yesterday, copy today and download CSV.

Dollars are list-price equivalents, an estimate. Plans are not billed this way.

Saving tokens

Diet tips for today and yesterday: heavy contexts, peak concurrency, marathon sessions, Opus subagents, spoiled cache and the note-taker's share. Each tip names the threads behind it. No message content is read.

Alerts

"Notify me" enables desktop notifications for a thread waiting on you, a cache about to go cold, a thread passing 85% context, one thread eating over 25% of the plate in 30 minutes, the plate passing 80% or running out before reset, and a summary after 20:00.

Sharing and privacy

A tiny /api/brief JSON summary for a menu-bar plugin or status line.

Screenshots can be taken safely with demo mode: open /?demo and the page loads synthetic fixtures instead of any live data. Read-only on ~/.t3, ~/.claude and ~/.codex. Metadata only. Binds to 127.0.0.1. No outside requests.

macOS first. Linux works for the server. Windows coming.

Quick start
cargo build --release
scripts/wamt start
scripts/wamt open
scripts/wamt login on        # optional: start at login, low priority
scripts/wamt statusline on   # optional: show the plate in Claude Code
