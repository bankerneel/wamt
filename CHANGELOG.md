# Changelog

## 0.1.0

First public release.

- Live view of T3 Code threads, runs, subagents, current step, context fill and tokens, plus Claude Code and Codex sessions outside T3.
- 5-hour plate with run-out forecast and Codex limit line; weekly meter; Claude Code `rate_limits` integration and a manual calibration fallback.
- Today, yesterday and the day before; week so far; 30-day history strip; PRs with checks and review states; spoiled leftovers; cost by model, thread and project.
- Diet tips, desktop alerts, tab title and favicon status, and a small `/api/brief` summary for menu-bar plugins.
- Status line wrapper for Claude Code, login item support via launchd, and CSV and clipboard exports.
- Demo mode with synthetic fixtures for screenshots and installations without T3 Code.
- Local-first design: read-only sources, metadata only, loopback-only HTTP, strict CSP and no outside requests.
